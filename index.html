Why this button can only work locally

Opening this dashboard from GitHub Pages calls Discord from fthyll.github.io. Discord blocks that cross-origin request, and the webhook URL must not live in a public page anyway. Run the site locally (python3 -m http.server) to use the button directly, or copy the payload below and paste it as a normal Discord message / via scrapers/broadcast.py.
